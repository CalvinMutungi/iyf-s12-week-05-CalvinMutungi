## Project Description
A robust, client-side To-Do List application built to demonstrate DOM selection, traversal, dynamic element manipulation, event delegation, and persistent local storage. Developed using GitHub Codespaces.

## Technologies Used
- HTML5
-CSS
-JAVASCRIPT 

## Features
- **CRUD Operations:** Create, complete, and delete tasks dynamically.
- **State Persistence:** Automatically saves and retrieves tasks using `localStorage`.
- **Event Delegation:** Uses a single root event listener to manage dynamically generated task actions.
- **Task Filtering:** Dynamically filter tasks across All, Active, and Completed states.
- **Input Security:** Basic HTML entity escaping to reduce the risk of cross-site scripting (XSS).

## Lessons Learned
- Efficiently selecting and traversing DOM nodes using modern methods such as `querySelector`, `children`, and `parentElement`.
- Implementing event delegation on parent containers to manage dynamically generated list items without attaching individual event listeners.
- Handling browser state persistence through JSON serialization and `localStorage`.
- Dynamically creating, updating, and removing DOM elements in response to user interactions.
- Organizing JavaScript code into modular functions for better readability and maintainability.
